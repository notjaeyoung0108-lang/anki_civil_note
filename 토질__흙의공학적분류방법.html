제1장 흙의 기본적 성질과 분류

9. 흙의 공학적 분류방법

한 줄 ― 체 두 개(No.4·No.200)로 굵기를 나누고, 물 두 값(wL, Ip)으로 찰기를 나눈다.

1동기 ― 왜 분류하는가

  • 분류는 암기 게임이 아니라 적은 시험값으로 흙의 성격을 압축해 통신하는 코드.
  • 재는 것은 둘뿐: 입경(굵기)·연경도(찰기). 기호 하나 → 거동 예측 → 설계 판단.
체계 만든 이 주 용도
통일분류법 USCS Casagrande 활주로·도로·흙댐·기초지반 범용 (가장 많이 씀)
AASHTO (개정 PR법) Hogentogler & Terzaghi 도로 노반재료 적부 판단

2물리적 그림 ― 굵기와 찰기, 두 개의 축

체 번호가 클수록 그물눈이 촘촘 → 통과 입자가 작다.

체 눈금 무엇을 가르나
No.4 4.75 mm USCS 의 자갈/모래
No.10 2.0 mm AASHTO 의 자갈/모래
No.200 0.075 mm 조립토/세립토 ― 가장 중요

두 축이 갈리는 이유:

  • 조립토(자갈·모래) ― 맞물림(마찰) 로 버틴다. 물에 성격이 잘 안 변한다 → 입도 로 분류.
  • 세립토(실트·점토) ― 전기화학적 힘 이 지배. 물 먹는 양이 성격을 바꾼다 → 연경도 로 분류.

조립·세립 경계값 (두 체계의 첫 차이)

조립토 (G,S) 세립토 (M,C,O)
USCS No.200 통과 50% 이하 50% 이상
AASHTO No.200 통과 35% 이하 35% 이상 (표는 36% 이상)
  • 35 vs 36 은 모순 아님 ― 정수로 끊은 같은 경계선.

3개념·정의 ― 기호 읽는 법

두 글자. 제1문자 = 흙의 종류, 제2문자 = 그 흙의 상태(품질). "형용사 + 명사"로 읽는다 (GW = Well-graded Gravel).

(1) 제1문자 ― 무슨 흙인가

G S M C O Pt
자갈 모래 실트 점토 유기질토 이탄
Gravel Sand Mo Clay Organic Peat
  • G/S 구분: No.4 통과율 50% 기준 ― 이하면 G, 이상이면 S.
  • 엄밀히는 "조립분 안에서 No.4 잔류가 절반 이상이면 자갈" ― 교재식은 세립분이 적을 때의 단순화.

(2) 제2문자 ― 붙는 자리에 따라 뜻이 갈린다

조립토(G·S)에 붙을 때:

문자 뜻 판정
W 입도 양호 세립분 5% 이하 + 입도조건 만족
P 입도 불량 세립분 5% 이하 + 입도조건 미달
M 실트질 함유 세립분 12% 이상 + A선 아래 (Ip≤4)
C 점토질 함유 세립분 12% 이상 + A선 위 (Ip≥7)

세립토(M·C·O)에 붙을 때 ― 기준은 액성한계 50%: L = 저압축성 wL≤50% / H = 고압축성 wL≥50%.

  • 자리가 다르면 주인공이 다르다. ML·CH = 흙 자체가 실트·점토 / SM·GC = 주인공은 모래·자갈, 섞인 세립분이 실트질·점토질.
  • H → wL 큼 → 압축·팽창 큼 → 구조물 밑에 위험.

4유도 ― 공식이 왜 그 모양인가

(1) 입도 판정 ― Cu, Cg (조립토가 W냐 P냐)

Cu=D60D10Cg=(D30)2D10D60
  • Cu = 입경 분포의 폭 (크다 = 여러 크기가 골고루). Cg = 곡선의 매끈함 (특정 크기가 안 빠짐).
  • 교재 오타 ― Cg 분자는 (D30)2. (D60)2 면 Cg=Cu 가 되어 무의미.

양호(W) 조건 ― 둘 다 만족해야 W, 하나만 어겨도 P.

자갈 GW 모래 SW
Cu ≥4 ≥6
Cg 1≤Cg≤3 좌와 동일 (공통)
  • 4↔6 방향 함정 단골 ― 모래가 더 엄격(작아서 더 다양해야 촘촘히 채워진다).

(2) 세립토 판정 ― 소성도표

A선:Ip=0.73(wL−20)U선:Ip=0.9(wL−8)
  • A선 위 → 점토 C / A선 아래 → 실트 M · 유기질 O.
  • B선 = wL=50% 수직선 → 왼쪽 L, 오른쪽 H.
  • U선 = 실측의 물리적 상한. 위쪽엔 흙이 없다 → 시험 오류 검출용.
위치 wL≤50 (L) wL≥50 (H)
A선 위 (점토 C) CL CH
A선 아래 (실트 M / 유기질 O) ML / OL MH / OH

(3) 이중기호 ― 경계에 걸치면 하이픈 병기. 두 상황뿐.

  • 세립분 5% 이하 = 순수 조립토(W/P) / 5~12% = 이중기호(GW-GM, SP-SC) / 12% 이상 = 세립분 지배(M/C).
  • 소성도 Ip 4~7 회색지대 → CL-ML(빗금 구역). Ip≤4 확실히 M, ≥7 확실히 C.

(4) AASHTO 군지수 GI

GI=0.2a+0.005ac+0.01bd
a b c d
P200−35 P200−15 wL−40 Ip−10
0~40 0~40 0~20 0~20
  • 음(-)이면 0 (기준 미달 = 벌점 없음), 결과는 가장 가까운 정수로 반올림, 실질 범위 0~20.
  • a,b = 세립분의 양, c,d = 그 세립분의 질(찰기). ac 교차항 = 많으면서 찰지기까지 하면 더 나쁘다.
  • GI 클수록 → 노반재료로 불량.

5단위·극한 검증

  • Cu, Cg 모두 입경끼리 나눈 무차원. Ip, wL 은 둘 다 % → A선 식 양변 정합.
  • Cu→1 → D60=D10 → 모든 알갱이가 같은 크기 → 균등(불량) → P.
  • A선에서 wL=20 → Ip=0 → 소성 없는 흙 = 실트.
  • GI 에서 P200≤35, wL≤40, Ip≤10 → a,c,d=0 → GI=0 → 조립토는 노반으로 우수.
  • (D60)2 오타도 차원은 맞다 → 차원이 맞아도 논리는 틀릴 수 있다.

6연결 ― 이미 배운 것, 앞으로 배울 것

  • §7-8 입도분포곡선 → D10,D30,D60 의 출처. 이 단원은 그 곡선을 판정 기준으로 승격.
  • §4-5 연경도 → Ip=wL−wp 가 소성도표 좌표. 세립토 분류 = Atterberg 한계의 응용.
  • 앞으로 ― CH 는 압밀침하·유효응력 에서 재등장. 기호는 이후 모든 장의 입구 표지판.

USCS vs AASHTO 차이 4가지 (빈출)

USCS AASHTO
① 조립/세립 경계 No.200 50% No.200 35%
② 자갈/모래 기준체 No.4 No.10
③ 자갈질·모래질 구분 명확 불명확
④ 유기질토 분류 있음 (O, Pt) 없음
  • 분류 필수요소 ― USCS: {No.200·No.4 통과율, wL, wp, Ip} / AASHTO: {No.200 통과율, wL, Ip, GI}.
  • 수축한계 는 두 체계 모두 쓰지 않는다 ― 함정.

7한눈 요약 ― 판정 순서

단계 묻는 값 갈림
1 No.200 통과율 ≤50 → 조립토 / ≥50 → 세립토
2·조립 No.4 통과율 → G / S 세립분% → W·P / 이중기호 / M·C
2·세립 A선 위/아래 → C / M·O wL vs 50 → L / H

한 문장: 체 두 개로 1문자, 계수·소성도로 2문자 ― 두 글자가 곧 흙의 성격이다.
