4. 사용성 및 내구성

한 줄 ― 강도설계가 "부서지나" 였다면 여기는 "평소에 쓸 만한가". 하중은 사용하중, 재료는 탄성, 대상은 처짐·균열·피로.

1동기 ― 안 부서지는데 왜 또

  • Mu≤ϕMn 을 통과해도 남는 것: 출렁임·칸막이벽 균열·누수·철근 부식 → 사용 불가.
  • 한계상태가 둘. 둘 다 만족해야 설계 완료.
강도 ULS 사용성·내구성 SLS
하중 계수하중 1.2D+1.6L 사용하중 D+L
재료 극한상태 탄성범위
기호 Mu, Mn, fy Ma, fs, δ, wk
  • ⚠ 두 쪽 기호를 섞으면 전부 틀린다.
  • 내구성은 시간축 추가 ― 균열 = 수분·산소·염화물의 통로 → "50년 뒤에도 철근이 사나".

4유도 ― 공식 세 개

(1) Mcr ― 탄성 휨공식의 역산

fr=McrytIg ⇒ Mcr=frIgyt=frZ,fr=0.63λfck
  • Ig/yt = 단면계수 Z. fck 꼴은 차원이 안 맞는 순수 경험식 (ACI psi 판 7.5λfc′).

(2) Ie ― 두 극단의 가중평균, 척도는 Mcr/Ma

Ie=(McrMa)3Ig+[1−(McrMa)3]Icr=Icr+(Ig−Icr)(McrMa)3
  • 두 꼴은 완전히 같은 식(뒤가 Branson 형). 지수 3 은 회귀로 얻은 경험값, 국내 시험은 3승.
  • 처짐은 재료역학 그대로: δi=5wl4/(384EcIe).

(3) 장기처짐 ― 시간이 처짐을 키운다

  • 크리프: 지속 압축응력 하에서 응력 그대로인데 변형이 늘어난다. 건조수축: 하중과 무관.
δlt=δiλΔ,λΔ=ξ1+50ρ′,δtotal=δi(1+λΔ)
  • 분자 ξ ― 시간이 쌓고 증가는 둔화. 분모 ― 철근은 크리프하지 않는다([[복철근직사각형보]] 동기 3).
  • 🚩 3 곱해지는 즉시처짐은 지속하중에 의한 것 (전체 활하중 아님).
  • 🚩 4 λΔ 로 나온 값은 추가분. ρ′=0·5년 → 총처짐 3배 ("2배" 는 오답).

5단위·극한 검증

  • 등분포는 w 가 단위길이당 힘(N/mm). λΔ 무차원 → ρ′ 는 소수(2% → 0.02).
  • Ma→Mcr → Ie→Ig / Ma≫Mcr → Ie→Icr. 두 극단 모두 옳다.
  • Ma=1.5Mcr → (1/1.5)3=0.30, 벌써 70% 이동. 균열은 강성을 아주 빠르게 먹는다.
  • Ma<Mcr 이면 식이 Ie>Ig 를 뱉는다 → 규정은 Ie≤Ig 로 자른다.

  • 5년(ξ=2.0)에서 ρ′ = 0 / 0.01 / 0.02 → λΔ = 2.0 / 1.33 / 1.00 → 총처짐 3배 / 2.33배 / 2배.
  • 분모 50 의 뜻: ρ′=2% 면 장기처짐이 반토막. ρ′→∞ 에서 λΔ→0 은 식의 한계.

6처짐의 제한 ― 계산할까, 두께로 때울까

최소두께 이상이면 계산 생략, 아니면 계산해서 허용처짐 이하임을 보인다.

(1) 문 ① ― 최소두께 (l = 경간)

부재 단순지지 일단연속 양단연속 캔틸레버
1방향 슬래브 l/20 l/24 l/28 l/10
보 l/16 l/18.5 l/21 l/8
  • 세 규칙: ① 보 > 슬래브 ② 구속↑ → 분모↑(단부 부모멘트가 돕는다) ③ 캔틸레버 압도적 불리(단순보의 9.6배).
  • fy≠400 보정: 표의 값 ×(0.43+fy700). 검산 ― fy=400 에서 1.0. ACI 판은 0.4.
  • fy ↑ → 계수 > 1 → 더 두껍게.
  • 🚩 5 전제 둘: 보통중량, 손상 쉬운 비구조요소를 지지하지 않는 부재. 걸리면 계산 필수.

(2) 문 ② ― 최대허용처짐

부재 고려할 처짐 한계
미부착 평지붕 활하중 순간처짐 l/180
미부착 바닥 활하중 순간처짐 l/360
손상 쉬운 것 부착 부착 후 처짐 (지속 장기 + 추가 활하중 순간) l/480
손상 염려 없는 것 부착 위와 같음 l/240
  • 엄격해지는 순서 l/180<l/240<l/360<l/480. 기준은 지붕 무관심 → 바닥 사람의 감각 → l/480 재료의 파단.
  • 💡 왜 "부착 후" ― 벽은 이미 처진 형상에 맞춰 붙는다. 깨는 건 그 뒤의 추가 처짐.

7균열 ― 폭이 문제다, 개수가 아니다

  • "균열은 그 수보다는 폭이 더욱 문제된다." RC에서 균열은 정상 ― 없으면 철근이 일을 안 하는 것.
  • 흡수할 총 신장량은 정해져 있다 → 잘게 나누는 것이 항상 이긴다.
요인 폭 왜
fs ↑ 증가 철근 변형률이 곧 균열. 가장 직접적
지름 ↑ 증가 단위면적당 부착 둘레가 작다 → 균열 간격 벌어짐
cc ↑ 증가 표면으로 오며 부채꼴로 벌어진다
ρ ↑ 감소 나눠 받아 fs 가 낮아진다
이형철근 감소 마디가 촘촘히 물어 분산

최선책: 가는 철근을 여러 개, 이형으로 촘촘히 ― As 는 그대로, 배치만 바꿔 이긴다.

  • 🚩 6 피복의 이중성(모순 아님): 표면 균열폭은 커진다(불리), 부식 방어거리는 길어진다(유리) → 규정은 허용치를 cc 에 비례 완화.

(3) 철근 간격 규정 ― 둘 중 작은 값 이하

①  s=375(kcrfs)−2.5cc②  s=300(kcrfs)
  • kcr/fs ― 습하거나(210) 응력이 크면 간격이 좁아진다 = 엄격 ✓
  • ①의 −2.5cc = "피복↑→균열폭↑" 보상. ②는 cc 없음 = 절대 상한.
  • 건조·fy=400(fs=266.7): ① 393.8−2.5cc, ② 315mm, 교차 cc=31.5mm → 실무 40~60mm 이므로 ①이 지배. 시험은 둘 다.
  • 표피철근: h≥900mm 깊은 보 복부 측면 h/2. 순수 균열 제어용.

8허용균열폭 ― 내구성의 정량 기준

  • wk≤wa. 세 관점: 내구성(부식) / 사용성·누수 / 미관.

(2) 강재 부식 ― 두 후보 중 큰 값이 허용치

건조 습윤 부식성 고부식성
철근 절대값 0.4mm 0.3mm 0.3mm 0.3mm
철근 cc 항 0.006cc 0.005cc 0.004cc 0.0035cc
긴장재 0.2mm · 0.005cc 0.2mm · 0.004cc - -
  • 환경이 험할수록 cc 계수가 작아진다. 긴장재가 엄격한 이유: 응력부식균열·수소취화 + 항상 인장 → 경고 없이 끊어진다.
  • 🚩 7 습윤·부식성이 같이 0.3mm 인 이유: 절대값은 바닥, cc 항은 보너스 ― 나빠지면 보너스만 깎인다.
  • 0.006cc=0.4⇒cc=66.7mm → 실무 피복에서는 절대값이 지배, 기준선 0.3mm.

(3) 수처리 구조물 ― 누수 방지

휨 인장 균열 전 단면 인장 균열
오염되지 않은 물 0.25mm 0.20mm
오염된 액체 0.20mm 0.15mm

9피로 ― 반복이 강도를 깎는다

  • 미세결함 끝단에서 사이클마다 균열이 자란다 → 경고 없는 취성파괴. 대상 도로교·철도교·크레인 거더.
항목 값·규정
콘크리트 피로한도 100만 회
압축 피로강도 정적강도의 50~55%
보·슬래브 휨 및 전단 검토
기둥 생략 가능 ― 축압축·사하중 지배라 변동폭이 작다
배근 고응력부에서 구부리지 말 것 ― 응력집중·잔류응력
  • 왜 철근인가: 과소철근보라 철근이 몰리고, 균열단면에는 인장 콘크리트가 없어 변동을 혼자 받는다.

(4) 응력범위 ― 충격 포함 사용 활하중에 의한 Δf=fmax−fmin 가 표 이내면 검토 불필요.

fy (MPa) 300 350 400 이상
허용 Δf (MPa) 130 140 150
  • 🚩 8 fmax=fD+fL, fmin=fD → Δf=fL. 사하중은 소거된다 ― 피로는 오르내리는 부분만. 그래서 활하중 비중이 큰 장경간 교량·크레인 거더가 취약.
  • fy 는 33% 늘었는데 허용치는 15% 만 → 피로강도는 정적강도에 비례하지 않는다. 고강도로 철근량 줄이면 피로에 불리.

11한 장 요약

  1. 강도는 계수하중·극한, 사용성은 사용하중·탄성. 기호를 섞지 말 것.
  2. RC 처짐의 어려움은 전부 "I 가 상수가 아니다" 에서 나온다. 대표값이 Ie.
  3. 균열은 개수가 아니라 폭 ― 가는 철근 여러 개, 촘촘히, 이형으로. 배치만 바꿔 이긴다.

  • 연속보는 Ie 를 평균. wk 계산식은 없다 → 간격 규정으로 간접 만족.
