6. 관측값의 처리방법

한 줄 ― 여러 번 잰 값에서 가장 믿을 만한 값(최확값)과 그 값의 신뢰도를 뽑아내는 법. 뿌리는 하나뿐이다 ― 잔차 제곱합 [vv] 를 최소로.

1오차의 분류 ― 처리법이 다르다

종류 원인 특징 처리
착오(과실) 사람의 실수 크고 불규칙 버린다(재측)
정오차(계통오차) 기계·환경의 일정한 편향 부호·크기 규칙적, 누적 보정식으로 제거
우연오차(부정오차) 미세 변동의 합 규칙 없이 ± 흩어짐 최소제곱법·확률론
  • 처리 순서: 착오 버림 → 정오차 보정 → 남은 우연오차가 이 단원의 대상.
  • "보정"이 되는 것은 정오차뿐. 착오는 보정식이 없고, 우연오차는 평균으로 줄일 뿐.

2왜 종 모양인가 ― 오차의 3법칙

  • 독립적인 미세 변동의 합 → 정규분포로 수렴(중심극한정리). 오차 이론 전체의 토대.
  • 큰 오차 = 미는 원인이 한쪽으로 몰릴 확률 → 드물다. +원인과 -원인은 대등 → 좌우대칭.

오차의 3법칙

  1. 큰 오차일수록 생길 확률이 작다 (꼬리는 얇다)
  2. 같은 크기의 +오차와 -오차는 확률이 같다 (좌우대칭)
  3. 극단적으로 큰 오차는 사실상 생기지 않는다 (꼬리는 0으로)

3확률곡선과 확률오차

편차 (×σ) 0.6745 1.000 1.645 1.960 3.000
포함 확률 50.0% 68.3% 90.0% 95.0% 99.7%

확률오차(probable error) = 분포의 딱 절반(50%)이 들어오는 범위. 크고 작을 확률이 반반인 경계.

r=0.6745σ
  • 승수 0.6745 는 단골 숫자 ― 그림의 넓이 절반으로 기억.

4최확값과 그 신뢰도 ― 핵심 공식

(1) 최확값 = 산술평균

같은 정밀도로 n 번 관측했을 때 최확값은 산술평균.

x¯=[l]n=l1+l2+⋯+lnn
  • 기호 약속: 대괄호는 가우스의 합(Σ). [l]=∑li, [vv]=∑vi2, [pl]=∑pili.
  • 평균은 관례가 아니라 최소제곱 원리의 결과(§5).

(2) 잔차와 평균제곱근 오차

잔차 vi= li−x¯. 관측 1회의 평균제곱근 오차:

m=±[vv]n−1

분모가 n 이 아니라 n−1 인 이유: 평균을 쓰느라 자유도 1개를 이미 소비.

우리가 실제로 보고하는 값은 평균이다 → 오차전파법칙으로 mx2=m2/n:

mx=±mn=±[vv]n(n−1)
  • 가장 중요한 식. 1회 오차를 n 으로 나눈 것이 평균의 오차.
  • 대상이 다르다 ― m = 관측 1회(늘려도 안 줄어든다), mx = 그 평균.
정밀도를 올리려면 2배 3배
관측 횟수 4배 9배
  • 1/n 로만 줄어든다 → 수확체감. 횟수를 늘릴수록 이득이 작아진다.

(3) 정밀도가 다르면 ― 경중률(weight)

p∝1m2
  • 오차가 작을수록 무겁게 본다.

가중평균(경중률 고려 최확값)과 그 오차:

xp=p1l1+p2l2+⋯+pnlnp1+p2+⋯+pn=[pl][p]
md=±[pvv][p](n−1)
  • pi 가 모두 같으면 (1)·(2)의 단순평균 식으로 환원 ― 일관성 확인.

5최소제곱법

잔차들이 동시에 생길 확률(정규분포 확률의 곱):

P=∏i=1nhπe−h2vi2=(hπ)ne−h2[vv]
  • 변하는 것은 지수 e−h2[vv] 뿐이고 지수가 음수 → P 가 최대이려면:
[vv]=v12+v22+⋯+vn2=최소
  • 즉 잔차 제곱합이 최소가 되게 하는 값이 최확값 → 최소제곱법. 우연오차 처리법.

평균이 최소제곱해임을 직접 확인 ― 등정밀에서 x 로 미분해 0:

ddx∑(li−x)2=−2∑(li−x)=0⇒x=∑lin=x¯

함정 2개

표기 조건
[vv] 최소 등정밀(같은 정밀도). h 가 공통이라 약분
[pvv] 최소 부등정밀(가중 일반형), p∝h2
  • h = 정밀도지수. 교재의 "π, e, h는 정수"는 "상수"의 오타([vv] 만 변수).

6보충 ― 최확값의 진짜 의미

  • 질문을 뒤집는다: "참값이 x 라면, 내가 얻은 이 관측값들이 나올 확률은?"
  • "최대로 만드는 확률"은 참값의 확률이 아니다(참값은 고정된 미지수).
  • 관측이 나올 확률 = 가능도. 최대로 하는 법 = 최대가능도(최우)법.
  • 비유: "야옹" → 고양이. 증거를 가장 잘 설명하는 가설을 고른다.
  • 후보가 너무 낮으면/높으면 관측값이 종의 얇은 꼬리에 걸린다 → 확률 작다.
  • 가능도 곡선의 봉우리는 산술평균에 놓인다.
L(x)=∏i=1nhπe−h2(li−x)2=(hπ)ne−h2[vv]
확률 최대⟺[vv] 최소⟺x=산술평균
  • 세 가지가 같은 한 가지의 다른 얼굴 ― 지수의 마이너스 때문일 뿐.

7극한 검증

식 극한 결론
r=0.6745σ σ→0 r→0 ― 안 흩어지면 오차범위도 0
mx=m/n n→∞ mx→0 ― 무한히 관측하면 평균은 참값에 수렴
mx=m/n n=1 mx=m ― 1회 관측은 평균=그 값
xp=[pl]/[p] pi 모두 같음 =[l]/n ― 단순평균으로 환원
  • 단위: m, mx = 관측량과 같은 단위, n = 무차원 → 일치.

항목 식
