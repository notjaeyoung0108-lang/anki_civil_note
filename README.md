# 정리노트 복습 사이트

`study/tools/build_review.py` 가 뽑는다. **정리노트 페이지 그 위에서** 복습한다 —
빈칸을 따로 카드로 떼어내지 않는다. 흐름을 보면서 채점하는 게 요점이니까.

```powershell
py study/tools/build_review.py            # 정리노트를 고쳤으면 다시 뽑는다
py study/tools/build_review.py --level 1  # 단원 페이지를 1단계로 열기
```

- `index.html` — 과목 패널(과목별 12주 히트맵) → 과목 화면(장·단원) → 설정. 한 파일이다.
- `n-<해시>.html` — 정리노트. 복습 모드가 들어 있다. 자체완결(서버·CDN 불필요).
  **파일 이름은 ASCII 해시**다 — 한글 파일명은 브라우저·웹서버·GitHub Pages·윈도 로케일
  어디서든 한 번씩 어긋난다(URL 인코딩, NFC/NFD 정규화, Jekyll 처리). 이름은 단원 경로에서
  만들어 고정이므로 다시 뽑아도 같은 파일에 덮인다. 어느 단원인지는 목록에서 보면 된다.
- `.nojekyll` — GitHub Pages 가 Jekyll 처리를 건너뛰게 하는 빈 파일.
- `manifest.webmanifest` · `icon-192.png` · `icon-512.png` · `sw.js` — 홈 화면에 얹어
  **앱처럼** 쓰기 위한 껍데기. 주소창 없이 전체화면으로 뜨고, 오프라인에서도 열린다.

## 앱으로 얹기

- **폰** — 사이트를 열고 공유 → `홈 화면에 추가`. 아이콘으로 들어가면 브라우저 껍데기 없이
  앱처럼 뜬다(`display: standalone`).
- **PC 크롬** — 주소창 오른쪽 설치 아이콘 → `설치`. 별도 창으로 열린다.
- 서비스워커가 모든 페이지를 미리 받아두므로 **비행기 모드에서도** 복습된다.
  (`file://` 로 직접 열 때는 서비스워커가 안 돌지만 페이지 자체는 자체완결이라 그냥 열린다.)

> **캐시 문제는 빌드 번호로 막았다.** 다시 뽑을 때마다 파일 mtime 으로 8자리 번호를 만들어
> 링크(`…html?v=9ffe9d52`)와 서비스워커 캐시 이름에 붙인다. 그래서 새로 뽑으면 브라우저가
> 옛 파일을 붙들 수 없다. 그래도 이상하면 `Ctrl+Shift+R`.
>
> 서비스워커는 **캐시부터** 내주므로, 새 빌드를 올려도 워커가 교체되는 그 한 번은 옛 화면이
> 그려진다. 그래서 새 워커가 자리를 잡는 순간 **딱 한 번 알아서 새로 그린다**(`controllerchange`).
> 새로고침 한 번이면 새 화면이 온다.
>
> **내가 지금 어느 빌드를 보고 있나** — `설정` 화면 맨 아래 `빌드 <날짜 시각 UTC>`.
> 고친 게 안 보이면 여기부터 본다. 시각이 그대로면 아직 안 올라간 것이고, 바뀌었는데도
> 화면이 그대로면 그때 캐시를 의심한다.

## 쓰는 법

툴바는 네 개다 — **`완성본` `빈칸` | `복습 시작` `학습완료`**.

**`빈칸` 은 접기 구조와 한 몸이다.** 단원을 열면 이 상태로 시작한다 — `### [n]` 제목만
죽 늘어선 뼈대가 보이고, 제목을 누르면 그 절이 펴지면서 내용이 **빈칸으로 가려진 채** 나온다.
소제목 `(1) (2)` 이 또 한 겹 접혀 있어서, 흐름 → 갈래 → 내용 순으로 내려간다.
흐름을 보는 일과 빈칸을 채우는 일이 같은 화면에서 일어나는 게 요점이다.

**`완성본`** 은 반대로 다 펴고 다 보여준다. 읽거나 인쇄할 때 쓴다.

그리고 **복습 시작**. 이때도 **뼈대는 그대로 있다** — 큐가 다음 빈칸으로 데려갈 때 그 절만
알아서 펴진다. 절 하나를 끝내면 다음 절이 열리는 식이라, 흐름을 보면서 채점하게 된다.
복습 중에는 **빈칸을 두 번** 누른다.

1. **한 번** — 그 빈칸이 `정답` 버튼이 된다 (아주 좁은 빈칸은 `?`).
2. **두 번** — 답이 열리고, 그 위에 `다시 / 어려움 / 일반 / 쉬움` 네 개만 뜬다.
   각 버튼에 다음에 언제 나올지가 찍혀 있다.

PC 와 폰 동작이 같다(클릭 = 탭). 폰에서는 A4 폭이 화면보다 넓으므로 **자동으로 축소**해
맞춘다(인쇄에는 영향 없음). 키보드: 스페이스/엔터 = 정답, `1`~`4` = 채점, Esc = 취소.

## 줄 간격

세로 스냅은 **2.5mm(반 칸)**, 인쇄되는 모눈은 5mm 다. 목록 항목 사이가 붙어 있던 것을
반 칸씩 띄우기 위해서다. 대가로 글줄이 모눈 칸 한가운데에 앉는 자리가 생긴다 —
화면으로 읽기엔 시원하지만 손으로 쓸 땐 줄이 안 맞을 수 있다.
되돌리려면 `render_note.py` 의 `SNAP` 을 `CELL` 로 바꾸고 `li + li` 여백을 지우면 된다.

## 접기 구조 — `빈칸` 이 켠다

따로 버튼이 없다. **`빈칸` 을 누르면(또는 단원을 열면) 접힌 상태로 시작한다.**
두 단계로 접힌다:

- `[1]`~`[12]` **제목**을 누르면 그 절이 펴지고, 안에 있던 `(1) (2) (3)` **소제목**이
  접힌 채로 드러난다.
- 소제목을 누르면 그 부분만 펴진다.

그래서 절의 흐름 → 절 안의 갈래 → 실제 내용 순으로 한 겹씩 내려갈 수 있다.

구조 보기에서는 **A4 로 나눈 종이를 없애고 한 장으로 이어 붙인다** — 종이 경계에서 절이
잘리면 흐름이 안 보이니까. 껐을 때 원래 쪽 나눔이 그대로 돌아오고, 접어둔 채 인쇄해도
원래 쪽 수 그대로 나온다(노드를 옮기지 않고 `display:contents` 로 상자만 빼기 때문). 쪽 나누기는 그대로 두되 쪽 높이를 풀어
접힌 만큼 빈 종이가 남지 않게 했다.

인쇄에는 영향이 없다 — 접어둔 채로 `Ctrl+P` 해도 원래 쪽 수 그대로 나온다.
복습 모드와 **같이 켜진다** — 큐가 필요한 절만 펴 주므로 뼈대를 잃지 않는다.

> `빈칸` 버튼이 가리키는 단계는 **그 파일이 열렸을 때의 단계**다. 사이트는 2단계로 열고,
> `--drill-level 3` 으로 뽑은 필기노트는 3단계로 돌아온다.
>
> `완성본` 과 `빈칸` 은 쪽 나눔이 서로 다르다(A4 vs 일자). 그래서 그 둘 사이에는 위치가
> 당연히 움직인다 — **같은 보기에서 단계만 바꿀 때** 0.000px 인 것이 지켜야 하는 성질이다.

## 세션 큐 — Anki 의 반복 루프

`복습 시작` 을 누르면 그 페이지의 **만기 빈칸 + 새 빈칸**으로 큐를 짜고 첫 번째로 데려간다.
채점하면 다음 빈칸으로 넘어가고, 상단에 `남은 것 12 · 다시 볼 것 3` 이 보인다.

동기화·학습완료 같은 알림은 화면 아래에 **팝업**으로 뜬다. 3초쯤 뒤 저절로 사라지고,
급하면 오른쪽 X 로 닫는다. 오류는 읽을 시간을 주려고 좀 더 오래 남는다.
글자는 잉크를 재서 알약 한가운데에 놓는다 — 한글은 밑으로 삐치는 획이 거의 없어
그냥 두면 2px쯤 위에 떠 보인다.
툴바 오른쪽 글자는 알림이 아니라 **큐 상태**(남은 것 / 다시 볼 것)다.

`다시(1분)` · `어려움(6분)` · `일반(10분)` 처럼 **분 단위**로 매긴 빈칸은 그 시간이 지나면
**답을 다시 덮은 채로** 큐에 돌아온다. 되돌아올 때 다시 가리는 게 핵심이다 —
답이 열린 채 돌아오면 인출이 아니라 그냥 읽기가 된다.

큐가 비고 돌아올 것도 없으면 `이 단원 오늘 몫 끝` 과 **다음 단원 링크**가 뜬다
(만기가 가장 많이 쌓인 단원으로 이어준다).

큐를 무시하고 아무 빈칸이나 눌러도 된다 — 누른 것이 큐보다 우선한다.

`단단함` 은 **그 빈칸이 얼마나 굳었나**를 세는 수다 — 학습단계(1분·10분)를 졸업했고
지금 복습 간격이 **21일 이상**인 빈칸의 개수. 오늘 처음 본 것이나 어제 겨우 맞힌 것은
빠지고, "이제 웬만해선 안 잊는다" 싶은 것만 남는다. 과목 패널의 막대는 그 비율이다.

**하루 새 빈칸 상한은 40개로 고정**이다(설정 화면에서 없앴다). 복습은 상한과 무관하게
전부 나온다. 상한이 없으면 201개짜리 단원을 한 번에 다 열게 되고, 그러면 다음 날 복습이
감당이 안 된다. 바꾸려면 `build_review.py` 의 기본값(`j0-cap`, 40)을 고친다.

채점한 빈칸에는 등급 색 줄이 남아 어디까지 했는지 보인다.

> 라벨은 빈칸 안에 **절대배치로 겹쳐** 그린다. 글자를 실제로 넣으면 폭이 변해 줄바꿈과
> 페이지 나눔이 달라지므로 그렇게 하지 않는다. 실측 레이아웃 변화 0.000px.

복습 모드를 끄면 원래대로 — 빈칸을 눌러 하나씩 열어보고, Ctrl+P 로 인쇄한다.

## 일정 (Anki 방식)

학습단계 `1분 → 10분` 을 지나면 졸업하고, 그다음부터 간격 × 용이도로 늘어난다.

| 버튼 | 학습 중 | 졸업 후 |
|---|---|---|
| 다시 | 1분, 처음 단계로 | 학습단계로 되돌아가고 간격 절반, 용이도 −0.2 |
| 어려움 | 6분, 단계 유지 | 간격 × 1.2, 용이도 −0.15 |
| 일반 | 다음 단계(10분) → 졸업 시 1일 | 간격 × 용이도 |
| 쉬움 | 즉시 졸업, 5일 | 간격 × 용이도 × 1.3, 용이도 +0.1 |

## 화면 세 칸 — 목록 · 과목 · 설정

**목록**은 과목 패널 여섯 개다. 패널 하나는 끝이 둥근 직사각형이고, 그 안에 **그 과목만의
12주 히트맵**이 촘촘하게 들어간다. 어느 과목을 며칠째 안 건드렸는지가 한눈에 보이는 게
요점이다. 오른쪽에는 `빈칸 본 것/전체`, `단단함`, 그리고 단단함 비율 막대.

**패널을 누르면 그 과목 화면**으로 들어간다 — 그 과목의 12주 히트맵(조금 크게)과
장별 단원 목록. 장은 눌러서 접고 펴며 **펼친 상태는 기억된다.** 단원을 누르면 정리노트로.

머리 왼쪽 `◀ 목록` 이나 **뒤로 가기 제스처**로 나온다(주소의 해시 한 칸만 쓴다).
단원 페이지의 `← 목록` 도 **그 과목 화면으로** 돌아온다.

머리 오른쪽 `설정` 에는 토큰 한 줄뿐이다.

과목 순서는 `SUBJECT_ORDER`(토목기사 과목 순), 표시 이름은 `SUBJECT` 에서 바꾼다.

`SYLLABUS` 에 교재 목차([파랑책] 6과목 231단원)를 적어둔 덕에 **아직 안 쓴 단원까지 회색
'아직' 으로** 뜬다 — 목록이 그대로 진도표다.

장 제목은 노트 첫 줄(`# 제N장 …`)을 먼저 쓰고 비어 있으면 `SYLLABUS` 에서 채운다.
단원 순서는 `## N.` 번호를 따른다. **그래서 새 노트를 쓸 때 첫 두 줄의 번호를 빠뜨리면
목록에서 뒤로 밀린다.**

목차의 단원 이름과 노트 제목은 괄호·공백·기호를 털어낸 뒤 맞춰본다(`_norm`).
새 노트를 썼는데 '아직' 이 안 없어지면 두 이름이 너무 다른 것이니 한쪽을 맞춰주면 된다.

## 기록은 어디에 있나

브라우저 **localStorage** (`j0-review-v1`). 단원 페이지와 목록이 같은 저장소를 본다.
빈칸의 이름표(rid)는 **내용에서 만든다** — 노트의 다른 곳을 고쳐도 그 빈칸의 기록은 살아남는다.

## PC ↔ 폰 자동으로 맞추기 (서버·DB 없음)

**누를 게 없다.** 깃 저장소의 파일 하나(`review-log.json`)를 두 기기가 공용 노트로 쓴다.
어느 저장소인지는 **빌드할 때 박힌다** — 기본은 사이트를 올린 그 저장소이고,
`--repo <계정>/<저장소>` 로 따로 지정할 수 있다(비공개 저장소에 기록만 담고 싶을 때).
빌드 첫 줄에 어디로 잡혔는지 찍히고, 앱의 `설정` 화면에도 그대로 보인다. 언제 오가나:

- **앱을 열 때(새로고침)** — 목록이 받아서 합치고, 올릴 게 있으면 올린다
- **단원의 `학습완료`** — 그 자리에서 같은 일을 한 번 더
- 단원 페이지를 **열 때는 받기만** (2분 안에 이미 맞췄으면 건너뛴다)

올릴 게 없으면 커밋을 만들지 않는다. 앱을 여닫는 것만으로 이력이 더러워지지 않는다.

### 토큰 — 쓰기에만 필요하다

저장소가 공개라서 **읽기는 토큰 없이** 된다. 토큰을 안 넣은 기기는 자동으로
**읽기 전용**이 된다 — 진도는 보이지만 그 기기에서 채점한 것은 올라가지 않는다.
(브라우저에서 깃에 쓰려면 자격증명이 반드시 필요하다. 이걸 없앨 방법은 없다.
사이트 코드에 토큰을 박으면 GitHub 의 비밀 검사가 곧바로 폐기해 버린다.)

**한 번만 준비:**

1. github.com → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → 이 사이트 저장소 하나만
   - Permissions → Repository permissions → **Contents: Read and write**
   - 다른 권한은 주지 않는다.
2. 목록 화면 오른쪽 위 **`설정`** → 토큰 붙여넣고 `저장`.
3. 폰에는 주소 끝에 **`#t=<토큰>`** 을 붙여 한 번 열면 저장된다. 예:
   `https://<계정>.github.io/<저장소>/#t=github_pat_...`
   (그 주소는 남기지 말고, 저장된 뒤에는 `설정` 화면으로 넘어간다.)

토큰은 그 브라우저에만 저장되고 어디에도 올라가지 않는다. 기기를 잃어버리면 GitHub 에서
그 토큰만 폐기하면 되고, 권한이 저장소 하나뿐이므로 최악의 경우도 거기에 갇힌다.

### 알아둘 것

- 기록 파일이 **공개 저장소**에 있다면 그 내용도 공개다. 안에는 노트 내용이 없다 —
  빈칸의 해시, 날짜, 점수, 단원 이름뿐이다. 그것도 싫으면 `--repo` 로 비공개 저장소를 쓴다.
- 합치기는 **양방향**이고, 같은 빈칸은 **복습 횟수가 많은 쪽**을 남긴다. 두 기기에서 같은 날
  공부해도 서로 지우지 않는다.
- 기록 저장소를 **사이트와 같은 저장소**로 뒀다면, 브라우저가 그 저장소를 직접 고치므로
  로컬에서 사이트를 다시 올릴 때 **`git pull --rebase` 를 먼저** 해야 밀리지 않는다.
  `--repo` 로 **따로 뒀다면** 사이트 push 와 아무 상관이 없다.
- 같은 저장소일 때 `review-log.json` 커밋마다 Pages 가 다시 배포되지만, 기록은 Pages 가
  아니라 GitHub API 로 읽으므로 배포가 늦어도 아무 영향이 없다.
- **기록 저장소를 비공개로 뒀다면 토큰 없는 기기는 읽지도 못한다.** 그럴 때 앱은
  "받지 못했습니다 — 기록 파일이 아직 없거나, 비공개 저장소라 토큰이 필요합니다" 라고
  말한다. 쓰는 기기마다 토큰을 넣어야 한다.
- 오류 문구는 원인을 그대로 알려준다: `401` 토큰 거부, `403` 권한 부족 또는 요청 초과,
  `GitHub 에 닿지 못했습니다` 는 인터넷/사내망 차단.
- 없앤 것: `기기 사이 맞추기`·`하루 새 빈칸 상한`·`파일로 옮기기` 카드.
  하루 새 빈칸 상한은 **40개로 고정**이고, 기록 백업은 깃 이력이 맡는다.

## 폰에서 열기 — GitHub Pages

⚠ **`J_0` 전체를 올리면 안 된다.** 루트에 `.env` 와 `secrets/` 가 있어 자격증명이 새어 나간다.
**`study/site` 만** 따로 저장소로 만든다.

```powershell
cd study\site
git init
git add .
git commit -m "정리노트 복습 사이트"
gh repo create j0-review --public --source=. --push
gh api -X POST repos/:owner/j0-review/pages -f "source[branch]=main" -f "source[path]=/"
```

1~2분 뒤 `https://<계정>.github.io/j0-review/` 에서 열린다. 홈 화면에 추가하면 앱처럼 쓴다.

갱신 — **`git pull --rebase` 를 먼저** 해야 한다. 브라우저가 `review-log.json` 을
저장소에 직접 쓰고 있어서 로컬이 뒤처져 있다.

```powershell
py study\tools\build_review.py     # 어느 폴더에서 돌려도 된다
cd study\site
git pull --rebase                   # 기록을 같은 저장소에 둘 때만 필요
git add -A && git commit -m "갱신" && git push
```

> `--notes` / `--out` 기본값은 **스크립트 위치 기준**이라 `study\site` 안에서 돌려도
> 제 갈 길을 찾는다. (예전엔 현재 폴더 기준이라 `site\study\notes` 를 찾고 죽었다.)

> **사이트와 기록이 모두 공개된다.** Pages 는 무료 계정에서 공개 저장소만 띄울 수 있고,
> 복습 기록(`review-log.json`)도 같은 저장소에 있으니 함께 공개다. 기록에는 노트 내용이
> 없다(빈칸 해시·날짜·점수·단원 이름뿐). 정리노트가 인터넷에 놓이는 게 싫으면
> **Cloudflare Pages + Cloudflare Access** — 무료 범위에서 구글 로그인 뒤로 숨길 수 있다.
